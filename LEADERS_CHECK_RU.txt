Naruto Shinobi Wars — проверка и исправление стартовых лидеров

РЕЗУЛЬТАТ
Исправлена привязка стартовых лидеров всех 8 стран через современную систему персонажей HOI4.

ЧТО БЫЛО НЕ ТАК
1. Файлы common/characters для SUN, KIR, NKU, IWA и OTO были пустыми заглушками.
2. В history/countries стартовые правители были созданы устаревшим create_country_leader без picture.
3. Стартовые персонажи не подключались через recruit_character. По документации character system, без recruit_character персонаж не может появиться в стране.

ЧТО ИЗМЕНЕНО
1. Добавлены персонажи-правители для KNO, SUN, KIR, NKU, IWA, OTO, AKA и MIN.
2. Все восемь стартовых правителей используют ideology = despotism, соответствующую группе neutrality.
3. В history/countries добавлен recruit_character для каждой страны до set_politics.
4. Удалены старые inline create_country_leader, чтобы избежать дублирования стартового лидера.
5. Для персонажей указаны civilian.large портреты через существующие spriteType из interface/portraits.gfx. Для MIN добавлен отдельный placeholder sprite.
6. Для имён и описаний добавлена локализация на русский и английский.
7. Сохранены дополнительные роли Pain, Итачи, Кисаме, Мадары, а также существующие лидеры/советники Конохи.

СТАРТОВЫЕ ПРАВИТЕЛИ
KNO — Хирузен Сарутоби; SUN — Четвёртый Казекаге; KIR — Третий Мизукаге; NKU — Третий Райкаге; IWA — Ооноки; OTO — Орочимару; AKA — Пейн; MIN — Совет малых стран.

СТАТИЧЕСКИЕ ПРОВЕРКИ
- Все 8 country tags имеют файл history/countries и соответствующий common/characters.
- В каждой истории страны recruit_character ссылается на объявленный character ID.
- Каждое объявление country_leader использует существующий GFX spriteType.
- Фигурные скобки проверены на баланс в изменённых файлах.
- ZIP проверен на целостность.

ОГРАНИЧЕНИЯ
Портреты в текущем архиве — generic placeholder textures, которые были подключены в прежнем interface/portraits.gfx; это не новые Naruto-иллюстрации. Для проверки фактического отображения нужно запустить игру с этим архивом. HOI4 в этой среде не запускалась.
