NARUTO SHINOBI WARS — РЕЙДЫ ПОД КАРТУ 5632x2048

Что включено:
- Воздушный удар по industrial_complex.
- Воздушный удар по прибрежной naval_base.
- Наземное проникновение генинов для саботажа industrial_complex.
- Морская диверсия специального батальона шиноби по прибрежной naval_base.
- Воздушная диверсия специального батальона шиноби по industrial_complex.

Привязка к карте:
- В истории карты проверены 8 industrial_complex и 8 naval_base.
- Цели выбираются по типам зданий и флагу is_coastal, а не по ванильным province/state ID.
- Не используются исторические country tags (GER, USA, JAP и т. п.).
- Восемь игровых тегов Naruto остаются без изменений: AKA, IWA, KIR, KNO, MIN, NKU, OTO, SUN.

Специальное подразделение:
- Добавлен батальон nsw_ninja_raider.
- Он помечен как special_forces, marines, can_exfiltrate_from_coast и can_be_parachuted.
- Его можно добавить в дивизионный шаблон; для морских и воздушных рейдов требуется хотя бы один такой батальон.

Ограничения старта:
- На старте карты нет air_base. Для воздушных и парашютных рейдов сначала нужно построить аэродром и обеспечить нужные самолёты.
- Морские рейды используют уже существующие naval_base; они есть в восьми штатах и привязаны к побережью.
- Наземное проникновение генинов требует genin-батальон, войну с целью и старт с дружественной военно-морской базы (рейд моделируется как высадка с побережья).
- Ядерные рейды пока выключены: на карте нет ядерных объектов/целей.
- Исторические vanilla *_custom raid packs оставлены пустыми, так как их теги и ID не соответствуют Naruto-карте.

Изоляция ванильных raid scripts:
- В descriptor.mod добавлен replace_path = "common/raids".
- Это намеренно исключает загрузку исторических vanilla raid definitions с тегами и ID старой карты.
- В моде оставлены все девять ожидаемых файлов рейдовой системы, с собственными определениями или пустыми types = { } для неподдерживаемых исторических пакетов.

Проверки:
- ZIP CRC / testzip.
- Сбалансированность фигурных скобок в каждом рейдовом .txt.
- Все referenced raid categories and custom battalion IDs exist.
- Target building types confirmed in the mod's state history: industrial_complex and naval_base.
- Actual in-game startup / raid launch was not tested in this environment.

Изменение совместимости: старт наземной диверсии перенесён с industrial_complex (недопустимая стартовая точка) на naval_base (допустимая стартовая точка); цель рейда по-прежнему industrial_complex.
